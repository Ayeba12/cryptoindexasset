# Public implementation: first batch

Scope: shared public layout, `/`, `/how-it-works`, `/copy-trading`. Extend the user-approved `/design-preview/home`; no new identity or concept round. Source content: the existing page drafts, without internal editorial notes or unsupported product claims.

## Direction contract

THESIS: make the account and decision process understandable; retain the approved product-led homepage.

OWN-WORLD: existing public zinc/yellow palette, Space Grotesk headings, Geist Mono text, CA-only branding and theme-paired product illustrations.

STORY: see the account, understand the steps, evaluate copying, confirm service details before funding.

FIRST VIEWPORT: homepage retains its centred two-line display, lead and paired actions; guides use the established inner-page scale and left-aligned text-led openings. Shared navigation stays above both.

FORM: approved incumbent extension; no seed or new composition choice. Preserve homepage bento rhythm and visible-by-default scroll reveals. Guides use sequential steps and editorial rows from their existing briefs.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Boundaries

No dashboard design, database, account actions or deployment changes. Public routes are staged with `noindex`. Unbuilt legal/contact/fee pages stay out of public navigation. No contact endpoint or verified trader data is invented. The copy-trading guide uses an evaluation CTA until an approved enquiry channel exists.

The exact public `/copy-trading` path is exempt from session middleware. Its subpaths remain protected. Existing dashboard links using this formerly unimplemented path need a dedicated account route during the dashboard phase; this batch does not change dashboard files.
