## Page copy

### W01 · Hero

H1: Know each step before you fund your account

Your account brings together balances, account activity and withdrawal requests. Read the process first so you know what information to check and when a request needs review.

Contents: Create an account · Check funding details · Review activity · Request a withdrawal.

### W02 · Process

H2: Create your account

Register with your details and follow the account setup instructions. Keep your sign-in details private and use a password you do not use elsewhere.

Link: Create account → `/register`

H2: Check the funding details

Sign in to view the deposit instructions. Check the asset and network before you send funds. If the destination or instructions are unclear, contact support before proceeding.

H2: Review account activity

Check the balances and entries recorded in your account. If an amount or status looks wrong, contact support with the relevant reference and a description of the issue.

H2: Request a withdrawal

Enter the withdrawal details and check the destination carefully. Submitting a request starts the review process. Check the current conditions, fees and expected timing before proceeding.

Link: Review fees → `/fees`

### W03 · Understanding status

H2: A request has more than one step

**Pending review.** The request has been received and is awaiting a decision.

**Approved.** The request has passed review. Check for separate transfer confirmation before treating it as completed.

**Declined.** The request was not approved. Read the reason provided or contact support for help.

**Completed.** The transfer has been confirmed. Keep the available transaction reference for your records.
